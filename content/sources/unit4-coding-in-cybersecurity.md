**Coding in Cybersecurity**  
**Coding** and being able to use **programming languages** to automate different tasks and processes are two very important skills that a person should have in order to work in the cybersecurity industry.   
An understanding of basic **programming** is crucial for success in cybersecurity. Although, some cybersecurity professionals never write a single line of code in their careers. It depends on the field that you are working in. For example: 

* Required skills for **penetration testers** include knowledge of programming languages such as **Perl**, **Java**, and **Python**.  
* Required skills for security engineers include knowledge of programming languages such as **Java**, **JavaScript**, **Python**, **SQL**, **PHP**, and others.

---

**There are approximately 250 popular computer programming languages. The most popular in the field of cybersecurity are**:

* **JavaScript**  
* **Python**  
* **Java**  
* **C/C++**  
* **PHP**  
* **SQL**  
* **Ruby**  
* **Perl**

**Java**  
**Java** is extremely popular in the IT world, and that is why it is important for cybersecurity professionals. **A variety of industry sources estimate that over 95% of enterprise desktops run Java, and  88% of all computers in the U.S. run Java.**

**JavaScript**  
**JavaScript** is the most popular and used language in the world. **Java** and **JavaScript** are two different **programming languages**. **JavaScript** is mostly used in **web development** to support interaction between the user and a **web application**. It also can be used by a **hacker** to embed **malicious code** into a legitimate website, which is then executed in the browser of a user who visits the website. 

**C/C++**  
Most **malware** is written in the **C/C++** **programming language,** which creates a need for proficiency in these languages for persons working in cybersecurity. 

**Python**  
The popularity of **Python** is growing every day because it is one of the easiest **programming languages** and it also can be used for almost everything, from automatizing simple processes and making your own job easier to developing **web applications**. 

**PHP**  
**PHP** is a general-purpose **scripting** language, which is also used to create various **web applications** and systems. 

**SQL**  
**Structured Query Language** or **SQL** is used for managing **databases**. **Databases** are crucially important in cybersecurity. For this reason, almost every person working in fields related to security knows this language. 

**Ruby**  
This programming language is similar to **Python** and **Perl**. **Ruby** is often used for **web development.** 

**Perl**  
**Perl** is mostly used for text manipulation and system administration processes. It is a great tool for any cybersecurity specialist because it helps to automate different security processes.

**Key Terms and Facts:**

* **There are approximately 250 popular computer programming languages**. In total, there are more than 700 programming languages. Although, most of them are very specific.   
* **A variety of industry sources estimate that over 95% of enterprise desktops run Java, and  88% of all computers in the U.S. run Java:** JavaScript is considered one of the most popular programming languages but Java is used on over 5.5 billion devices.  
* **Coding**: A part of programming that deals with writing codes that a computer can understand.  
* **Programming language**: A system of notation used to create applications.   
* **Programming**: The process of writing computer programs.  
* **Penetration test**: An authorized, simulated cyberattack made by a specialist in order to discover system vulnerabilities.  
* **Web development**: The process of developing a website.  
* **Web application**: A program that can be accessed through web browsers.  
* **Hacker**: A person who gains access to programs or information without authorization.  
* **Malicious code**: Harmful for a computer or a program code that creates vulnerabilities.   
* **Malware**: A software program that is designed to damage or/and gain unauthorized access to a computer.   
* **Scripting**: A way of programming that tells the computer what to do, when to do, and how to do specific tasks.  
* **Database**: Data stored in a structure within a computer.
