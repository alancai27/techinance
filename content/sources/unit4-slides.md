**Importance of coding skills**

Coding and being able to use programming languages to automate different tasks and
processes are two very important skills that a person should have in order to work in
the cybersecurity industry.

Understanding of basic programming is crucial for success in cybersecurity.

---

**Most used programming languages**

There are approximately 250 popular computer programming languages.

**Java:** Java is extremely popular in the IT world, and that is why it is important
for cybersecurity professionals. A variety of industry sources estimate that over 95%
of enterprise desktops run Java, and 88% of all computers in the U.S. run Java.

**JavaScript:** JavaScript is the most popular and used language in the world.
JavaScript is mostly used in web development to create the ability of interaction
between the user and a web application.

**Python:** Python is considered to be one of the easiest programming languages. It
also can be used for almost everything, from automatizing simple processes and making
your own job easier to developing web applications.

**The dictionary for this unit**

* **Scripting:** A way of programming that tells the computer what to do, when to do,
  and how to do specific tasks.
* **Programming language:** A system of notation used to create applications.
* **Programming:** The process of writing computer programs.
* **Penetration test:** An authorized, simulated cyberattack made by a specialist in
  order to discover system vulnerabilities.
* **Hacker:** A person who gains access to programs or information without
  authorization.
* **Programmer:** A person that uses programming languages to write programs and
  applications.
* **Malware:** A software program that is designed to damage or/and gain unauthorized
  access to a computer.
* **Command:** An instruction that causes the computer to perform one of its functions.
* **Variable:** A data item that can take more than one value during the runtime of a
  program.
* **Database:** Data stored in a structure within a computer.
* **Console:** The text area where you can see the output of a program or input your
  commands.
* **Malicious code:** Harmful for a computer or a program code that creates
  vulnerabilities.
* **Function:** Multiple lines of code that are written to accomplish a specific task.
